# Contributing

Thank you for contributing to ECC Curator.

## Core Principles

Contributions must preserve:

- Deterministic First
- Governance Before Optimisation
- Local First
- Provider Neutrality
- Context as Portfolio

## Architecture Boundaries

ECC Curator owns:

- Governance
- Policies
- Scoring
- Budgeting

Providers own:

- Compression execution
- Transformation execution
- Decision proposals

Providers must not bypass governance.

## MVP Priorities

Current priority:

- Inventory
- Scoring
- Governor
- Prompt Assembler
- Evaluation

Out of scope:

- Provider-specific features
- Cloud dependencies
- Vendor lock-in

## Pull Request Checklist

- Tests pass
- Documentation updated
- ADR impact considered
- No violation of deterministic-first principles
